# Sai Kiran Parlapalli — Data Scientist Portfolio

A responsive, static portfolio website designed around the supplied resume and portfolio brief. Built with HTML, CSS, and vanilla JavaScript so it can be published to Netlify without a build step or backend.

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser. For best results, use a simple local server such as VS Code's Live Server extension.

## Included features

- Responsive, accessible navigation and mobile menu
- Scroll reveal effects with reduced-motion support
- Responsive custom-built analytics dashboard in the hero
- Five custom vector project thumbnails (16:10 SVGs)
- Project category filters and keyboard-friendly case-study modals
- Interactive skill category filters
- Resume PDF download and open-in-new-tab link
- Functional contact-form behavior that opens a pre-filled email draft (the site does not send email automatically)
- Search / sharing metadata and custom favicon

## Where your files and links are

- Resume: `assets/Sai_Kiran_Parlapalli_Resume.pdf`
- Email, LinkedIn, and GitHub links are based on the live links embedded in the supplied resume.
- The site does not fabricate project demos or repositories. Add real project links only when you have verified URLs.

## Change content

- Main text and sections: `index.html`
- Visual styling: `styles.css`
- Filters, menus, modals, and contact form: `script.js`
- Custom thumbnail and visual assets: `assets/`

## Accuracy notes

- The hero chart and dashboard are illustrative; they are explicitly labelled as demo visuals, not production model data.
- Project cost savings are described as potential estimates when the resume describes them that way.
- CLU Cruze is described as a proposed solution, not a deployed application.
- ML accuracy figures are scoped to selected datasets and the stated evaluation setup.
- The contact form opens a draft in the visitor's default email application; it is not a backend form submission service.
